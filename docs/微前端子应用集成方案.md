## 1. 技术方案概述

### 1.1 方案背景

基于 qiankun 微前端框架，实现多技术栈子应用的统一集成和管理。基座应用作为主应用，负责子应用的注册、加载、卸载和通信协调。

### 1.2 技术选型

| 组件 | 技术栈 | 版本 | 说明 |
|------|--------|------|------|
| 基座应用 | React + TypeScript + Vite | 18.x | 主应用，负责子应用管理 |
| 子应用1 | Vue 3 + TypeScript + Vite | 3.x | Vue 技术栈子应用 |
| 子应用2 | React + TypeScript + Vite | 18.x | React 技术栈子应用 |
| 微前端框架 | qiankun | 2.x | 阿里开源微前端解决方案 |
| 构建工具 | Vite | 7.x | 现代化构建工具 |

### 1.3 架构优势

- ✅ **技术栈无关** - 支持 React、Vue、Angular 等多种技术栈
- ✅ **独立开发** - 各子应用可独立开发、测试、部署
- ✅ **渐进式升级** - 可逐步将现有应用改造为微前端架构
- ✅ **样式隔离** - 完善的 CSS 隔离机制
- ✅ **状态共享** - 基座与子应用间的数据通信
- ✅ **统一管理** - 统一的路由、权限、主题管理

```typescript
import vue from '@vitejs/plugin-vue';

  plugins: [
    vue(),
    qiankun('vue-app', {
      useDevMode: true

  ],

    port: 3001,
    cors: true,
    origin: 'http://localhost:3001'
  },
  build: {
    target: 'esnext',
    lib: {
      name: 'vue-app',
      entry: './src/main.ts',
      formats: ['umd']
    },
    rollupOptions: {
      external: ['vue'],
      output: {
        globals: {
          vue: 'Vue'
        }
      }
    }
  }
});
```

#### 3.1.3 主入口文件

```typescript
// src/main.ts
import { createApp } from 'vue';
import { createRouter, createWebHistory } from 'vue-router';
import { renderWithQiankun, qiankunWindow } from 'vite-plugin-qiankun/dist/helper';
import App from './App.vue';
import routes from './router';

let app: any;
let router: any;
let history: any;

/**
 * 渲染函数
 */
function render(props: any = {}) {
  const { container, routerBase } = props;
  
  history = createWebHistory(routerBase || '/vue-app/');
  router = createRouter({
    history,
    routes,
  });

  app = createApp(App);
  app.use(router);
  
  const containerEl = container ? container.querySelector('#app') : '#app';
  app.mount(containerEl);
}

/**
 * qiankun 生命周期 - 独立运行时
 */
renderWithQiankun({
  mount(props) {
    console.log('Vue app mount', props);
    
    // 接收主应用传递的状态管理方法
    if (props.setGlobalState) {
      // 保存到全局，供子应用使用
      (window as any).setGlobalState = props.setGlobalState;
    }
    
    render(props);
  },
  bootstrap() {
    console.log('Vue app bootstrap');
  },
  unmount() {
    console.log('Vue app unmount');
    app?.unmount();
    app = null;
    router = null;
    history?.destroy();
  },
});

/**
 * 独立运行
 */
if (!qiankunWindow.__POWERED_BY_QIANKUN__) {
  render();
}
```

### 3.3 子应用开发约束

#### 3.3.1 强制要求

- ✅ **导出生命周期** - 必须导出 bootstrap、mount、unmount 生命周期函数
- ✅ **路由配置** - 使用 basename/base 配置子应用路由前缀
- ✅ **资源路径** - 使用相对路径或配置 publicPath
- ✅ **全局变量** - 避免污染全局变量，使用命名空间
- ✅ **样式隔离** - 使用 CSS Modules 或 scoped 样式

#### 3.3.2 推荐实践

- 🔸 **状态管理** - 使用子应用内部状态管理，通过 props 与主应用通信
- 🔸 **API 请求** - 统一使用主应用提供的请求工具
- 🔸 **错误处理** - 实现完善的错误边界和异常处理
- 🔸 **性能优化** - 合理使用懒加载和代码分割

## 5. 通信机制

### 5.1 全局状态通信

#### 5.1.1 基座应用设置状态

```typescript
// 基座应用中
import { setGlobalState } from '@/config/qiankun';

// 设置用户信息
setGlobalState({
  user: {
    id: '1',
    name: '张三',
    avatar: 'https://example.com/avatar.jpg'
  },
  theme: 'dark'
});
```

#### 5.1.2 子应用监听状态

```typescript
// Vue 子应用中
export default {
  mounted() {
    // 监听全局状态变化
    if (window.onGlobalStateChange) {
      window.onGlobalStateChange((state, prev) => {
        console.log('状态变化:', state, prev);
        // 更新子应用状态
        this.globalState = state;
      });
    }
  }
}

// React 子应用中
useEffect(() => {
  if (window.onGlobalStateChange) {
    const unsubscribe = window.onGlobalStateChange((state, prev) => {
      console.log('状态变化:', state, prev);
      setGlobalState(state);
    });
    
    return unsubscribe;
  }
}, []);
```

### 5.2 事件通信

#### 5.2.1 自定义事件

```typescript

// React 子应用错误边界
class ErrorBoundary extends React.Component {
  constructor(props) {
    super(props);
    this.state = { hasError: false };
  }

  static getDerivedStateFromError(error) {
    return { hasError: true };
  }

  componentDidCatch(error, errorInfo) {
    console.error('子应用错误:', error, errorInfo);
  }

  render() {
    if (this.state.hasError) {
      return <h1>应用出现错误，请刷新重试</h1>;
    }

    return this.props.children;
  }
}
```

## 8. 常见问题

### 8.1 路由问题

#### 问题：子应用路由不生效

**原因**: 路由 base 配置不正确

**解决方案**:
```typescript
// 确保子应用路由配置正确
const router = createRouter({
  history: createWebHistory('/vue-app/'), // 注意斜杠
  routes
});
```

#### 问题：刷新页面 404

**原因**: 服务器未配置 SPA 路由

**解决方案**:
```nginx
# Nginx 配置
location /vue-app {
    try_files $uri $uri/ /vue-app/index.html;
}
```

### 8.2 样式问题

#### 问题：样式冲突

**原因**: 全局样式污染

**解决方案**:
```typescript
// 启用严格样式隔离
start({
  sandbox: {
    strictStyleIsolation: true
  }
});
```

#### 问题：第三方组件库样式丢失

**原因**: 样式隔离过于严格

**解决方案**:
```typescript
// 使用实验性样式隔离
start({
  sandbox: {
    strictStyleIsolation: false,
    experimentalStyleIsolation: true
  }
});
```

### 8.3 通信问题

#### 问题：子应用无法接收全局状态

**原因**: 生命周期函数中未正确处理 props

**解决方案**:
```typescript
// 确保在 mount 生命周期中保存通信方法
renderWithQiankun({
  mount(props) {
    // 保存到全局变量
    window.setGlobalState = props.setGlobalState;
    window.onGlobalStateChange = props.onGlobalStateChange;
  }
});
```

### 8.4 构建问题

#### 问题：子应用构建后无法加载

**原因**: 构建配置不正确

**解决方案**:
```typescript
// 确保 UMD 格式构建
export default defineConfig({
  build: {
    lib: {
      name: 'vue-app',
      entry: './src/main.ts',
      formats: ['umd']
    }
  }
});
```

### 8.5 性能问题

#### 问题：首屏加载慢

**解决方案**:
1. 启用预加载: `prefetch: 'all'`
2. 使用 CDN 加速资源加载
3. 合理拆分代码块
4. 启用 gzip 压缩

#### 问题：内存泄漏

**解决方案**:
```typescript
// 确保在 unmount 时清理资源
renderWithQiankun({
  unmount() {
    // 清理定时器
    clearInterval(timer);
    // 移除事件监听
    window.removeEventListener('resize', handler);
    // 销毁应用实例
    app?.unmount();
  }
});
```
